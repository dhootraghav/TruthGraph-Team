# Owner/base handoff

Create the new empty GitHub repository, initialize `main`, extract this ZIP into the repository root, push the base, and invite teammates. This base intentionally lacks frontend and specialized backend/graph modules until the other branches merge.

After merging teammates' PRs, verify SHA-256 manifest, install dependencies, run backend tests and a live browser demo, and record actual integration and review work.

Original application code is preserved and attributed to its original developer.
