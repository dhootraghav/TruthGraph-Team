# Frontend package handoff

Original source files are under `frontend/`. Extract the ZIP into the ROOT of your NEW repository checkout; do not put a `frontend/` directory inside another `frontend/`.

Branch: `feature/frontend-integration`.

Perform and record actual work: review the React/Vite project, run `npm ci`, start `npm run dev`, inspect homepage/verification/results/history/about pages, and record browser compatibility or accessibility findings. Test the final merged app with a live backend. Submit your PR with truthful test results.

Do not claim to have originally authored the imported source if you did not. Do not commit `node_modules/` or `.env`.
